# PhoneKey Unlock v0.1.0 — 2026-10-28

Initial release. QR/manual pairing, multiple phones per account, AES-256-GCM
vault with the key only on the phone, Ed25519 + one-time challenge unlock
test with anti-replay, Wake-on-LAN, CLI + Tkinter GUI, logs/debug, and an
auto-update check against this repo.

Limit: v0.1 does not hook the OS login screen (Windows Credential Provider /
Linux PAM / macOS plugin). It verifies pairing, challenge and vault only.
